## Описание проекта

- **Планировщик расписания** — веб-приложение на чистом JavaScript (Vanilla JS) для организации задач и планирования времени.
- **Основная цель**:
  - помочь пользователю структурировать задачи на определённое время;
  - распределять задачи по важности;
  - отслеживать просроченные задачи;
  - контролировать выполнение задач.
- **Возможности приложения**:
  - добавление новых задач;
  - указание описания, даты и времени выполнения;
  - выбор уровня важности;
  - отметка задач как выполненных.
- **Визуальная система подсветки**:
  - просроченные задачи — красный оттенок;
  - задачи с дедлайном менее одного дня — оранжевый оттенок;
  - выполненные задачи — перечёркивание и крестик.
- **Технологический стек**:
  - без сторонних JavaScript-фреймворков;
  - DOM API, события, массивы объектов, модули, ES6+.

---

## Основные функции проекта

- **Работа с задачами**:
  - добавление новых задач;
  - отображение списка задач;
  - сохранение задач после перезагрузки страницы;
  - изменение статуса выполнения задачи;
  - автоматическое обновление интерфейса.
- **Планирование**:
  - выбор даты и времени выполнения;
  - фильтрация задач:
    - день;
    - неделя;
    - месяц;
    - год.
- **Приоритет задач** (уровни важности):
  - Очень важно;
  - Важно;
  - Среднее;
  - Минимально.
- **Визуальная система состояний**:
  - просроченные задачи — красный оттенок;
  - задачи с близким дедлайном — оранжевый оттенок;
  - выполненные задачи — перечёркивание.
- **Интерфейс**:
  - адаптивный современный интерфейс;
  - мягкая цветовая палитра;
  - карточки задач;
  - hover-анимации;
  - удобное расположение блоков.

## Инструкция по установке и запуску

- **1. Скачать проект**:
  - скачать проект или клонировать репозиторий:
    - `git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ`
- **2. Открыть проект**:
  - открыть папку проекта в Visual Studio Code.
- **3. Установить расширение**:
  - установить расширение: **Live Server**.
- **4. Запуск проекта**:
  - нажать правой кнопкой мыши на файл: `index.html`;
  - выбрать: `Open with Live Server`;
  - после этого проект откроется в браузере.

## Пример использования

- **Добавление задачи**:
  - 1. Ввести название задачи;
  - 2. Добавить описание;
  - 3. Выбрать дату и время;
  - 4. Указать важность;
  - 5. Нажать кнопку «Добавить».
- **Результат**:
  - после этого задача появится в списке задач.
